THE FIX (core/mempool.cc, include/osv/mempool.hh; gated CONF_fork)
================================================================================
The shared kernel small-object pool lives in the identity map (PML4 slots
128..511, shared verbatim in every fork AS -- it is NOT COW-cloned; verified:
the RUN-3 freed page 0x400126238000 and its 0x500 page-alias both decode to
shared kernel slots 128/160).  So the prior "pool pages participate in fork COW"
framing is WRONG; the real root is a lock-free use-after-free:

  pool::free_same_cpu could return a backing page to page_pool (untracked_free_page)
  while the lock-free MPSC garbage queue (unordered_queue_mpsc<free_object>) still
  linked into that page via intrusive free_object::next -- a producer's in-flight
  link store or the consumer's _poll_list look-ahead then wrote/read an 8-byte
  pointer into the recycled page (the RUN-3 signature: a 0x500 page-alias pointer
  stored at off 1128 of a freed 0x400 page).

Fix (all under #if CONF_fork; conf_fork=0 -> byte-identical stock OSv):
  - free_same_cpu never frees a pool page inline; it completes the free onto
    local_free so the page stays fully-free on the per-CPU pool _free list and
    bumps a per-CPU empty tally (_nr_empty).
  - collect_garbage, AFTER draining EVERY incoming garbage sink for the CPU (the
    single-consumer, preempt-locked quiescent point where _head==_poll_list==null
    for every sink, so no MPSC link references any pool object), calls
    flush_all_empty_pages -> flush_empty_pages, which releases each malloc pool's
    SURPLUS empties (> max_retained_empty=4 per CPU) back to page_pool.  The page
    is erased from _free BEFORE the DROP_LOCK+untracked_free_page, so no concurrent
    same-CPU alloc can re-grab it during the drop.
  - alloc keeps _nr_empty honest when a page leaves the fully-free state (0->1).
  - Bounded retention (max_retained_empty) so a bursty free storm cannot pin
    unbounded memory (naive never-reclaim -> OOM-then-fault).

Correct under SMP: producers push to per-CPU sinks concurrently; the single
consumer drains all sinks under that CPU's preempt_lock before flushing; a
retained empty page (nalloc==0) has all objects on local_free and none queued,
so it is MPSC-safe by construction.
